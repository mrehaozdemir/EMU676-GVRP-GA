# Green Vehicle Routing Problem (GVRP) using a Genetic Algorithm

## Overview

This repository contains the implementation developed for the EMU676 Metaheuristics course project.

The project addresses the Green Vehicle Routing Problem (GVRP), where fuel consumption depends on vehicle load. A Genetic Algorithm (GA) is used to minimize total fuel consumption while satisfying vehicle capacity constraints.

## Features

* Permutation-based chromosome encoding
* Capacity-constrained route decoder
* Tournament selection
* Order Crossover (OX)
* Swap mutation
* Inversion mutation
* Elitism
* Convergence tracking
